# 🤖 AI Quiz Telegram Bot

Интерактивный Telegram-бот на базе Node.js, который превращает фотографии и скриншоты тестов в полноценные интерактивные викторины (Telegram Quiz). Бот использует зрение нейросети Google Gemini для анализа текста вопросов и вариантов ответов, автоматически находит выделенный правильный ответ и запускает пошаговую игру с подсчетом итоговых баллов.

## ✨ Ключевые особенности

* **Мультимодальный анализ:** Распознавание текста и визуальных элементов (галочек, радиокнопок) на скриншотах с помощью модели `gemini-3.5-flash-lite`.
* **Умная обработка альбомов:** Группировка одновременно отправленных фотографий (Debounce) для предотвращения спама в чате и удобного UX.
* **Интерактивный режим игры (State Machine):** Бот последовательно выдает вопросы. При выборе ответа старый опрос удаляется с задержкой 2.5 секунды, и моментально появляется новый. В конце выводится статистика и процент правильных ответов.
* **Перемешивание ответов:** Автоматическое тасование вариантов ответов (алгоритм Фишера-Йетса) с динамическим пересчетом индекса правильного ответа.
* **Мультиязычность:** Автоматическая адаптация интерфейса под язык пользователя в Telegram (Русский, O'zbekcha, English) с точным сохранением оригинального языка на фото без искажений и перевода.
* **Отказоустойчивость (Production-Ready):**
* Кастомный парсер JSON через регулярные выражения `\{[\s\S]*\}` для защиты от «грязных» ответов нейросети.
* Система `Retry` с экспоненциальной задержкой для обхода ошибок `503`, `429` (Quota exceeded) и таймаутов Google API.
* Обход жесткого лимита Telegraf (90 секунд) за счет выноса тяжелой генерации в фоновые процессы.



## 🛠 Технологический стек

* **Язык:** JavaScript (Node.js, ES Modules)
* **Фреймворк:** [Telegraf.js](https://telegraf.js.org/) (Telegram Bot API)
* **AI интеграция:** `@google/generative-ai` (Gemini Vision API)
* **Конфигурация:** `dotenv`

## 🚀 Установка и запуск

### 1. Подготовка

Убедитесь, что у вас установлен [Node.js](https://nodejs.org/) (рекомендуется версия 18.x или выше).

### 2. Клонирование репозитория

```bash
git clone <url_вашего_репозитория>
cd <папка_проекта>

```

### 3. Установка зависимостей

```bash
npm install telegraf @google/generative-ai dotenv

```

### 4. Настройка переменных окружения

Создайте файл `.env` в корневой директории проекта и добавьте ваши API-ключи:

```env
TELEGRAM_TOKEN=ваш_токен_от_BotFather
GEMINI_API_KEY=ваш_ключ_от_Google_AI_Studio

```

*(Для увеличения лимитов запросов можно реализовать ротацию нескольких ключей Gemini).*

### 5. Запуск бота

```bash
node index.js

```

В консоли должно появиться сообщение: `✅ Бот запущен! Архитектура: "Сначала анализ, затем игра" активна.`

## 🧠 Архитектура работы (Машина состояний)

Процесс обработки разделен на две изолированные фазы:

1. **Фаза сбора и анализа (`state: 'analyzing'`):**
* Бот накапливает массив `file_id` входящих фотографий.
* После нажатия кнопки "Начать анализ", запускается фоновый процесс `processBatchBackground`.
* Каждое фото отправляется в Gemini API. В случае сбоя серверов Google срабатывает механизм авто-повтора (до 3 попыток с паузой 5 секунд).
* Успешно распознанные и перемешанные тесты сохраняются во внутреннюю память (`userSessions`).


2. **Фаза игры (`state: 'playing'`):**
* Бот вызывает метод `telegram.sendQuiz` с параметром `is_anonymous: false`.
* Событие `bot.on('poll_answer')` перехватывает ответ пользователя, сверяет его с индексом правильного ответа в памяти сессии и начисляет балл.
* Через 2.5 секунды старый опрос удаляется из чата, и из памяти мгновенно выдается следующий тест.



## 📝 Требования к фотографиям

* На скриншоте должен быть четко виден вопрос и варианты ответов.
* Правильный вариант ответа должен быть визуально выделен (например, синим кружком/рамкой интерфейса приложения).
* Для стабильной работы на бесплатном тарифе API рекомендуется загружать партии до 5-10 фотографий за один раз во избежание ошибки `429 Too Many Requests`.
